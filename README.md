# Ganadero.org PySpark Teaching Lab

All records are synthetic.

## Setup

1. Install Java compatible with your Spark distribution.
2. Run `pip install pyspark jupyterlab`.
3. Extract this ZIP and open a terminal in this folder.
4. Run `jupyter lab` and open `Ganadero_Livestock_Analytics_PySpark.ipynb`.
5. Run cells in order. Spark output is written under `output/`.

Files: farms, animals, weights, health events and births (CSV).
